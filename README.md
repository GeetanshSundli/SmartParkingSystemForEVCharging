# Smart Parking and EV Charging Management System

The Smart Parking & EV Charging Management System is a modular Java application built using core Object-Oriented Programming principles. It models a multi-tier parking facility that manages motorcycles, standard cars, and electric vehicles across specialized parking spots and EV charging bays.

During execution, the system validates vehicle-to-spot compatibility, checks charger wattage requirements for electric vehicles, and prioritizes optimal spot allocation to prevent double-booking. It issues time-stamped entry tickets and dynamically calculates exit fees using interchangeable pricing strategies—applying hourly rates for regular parking and combined parking-plus-kilowatt-hour billing for EV charging—while enforcing strict state rules and custom exception handling.
